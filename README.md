# Simple Weather Station — Arduino

[![C++](https://img.shields.io/badge/C++-00599C?style=for-the-badge&logo=cplusplus&logoColor=white)](https://isocpp.org)
[![Arduino](https://img.shields.io/badge/Arduino-00979D?style=for-the-badge&logo=arduino&logoColor=white)](https://arduino.cc)

*A local weather station measuring temperature, humidity, and atmospheric pressure — displayed on an LCD in real time.*

</div>

---

## Sensors & display

| Component | Measurement |
|---|---|
| DHT11 / DHT22 | Temperature + humidity |
| BMP180 / BMP280 | Atmospheric pressure + altitude |
| 16×2 LCD (I2C) | Real-time display |

---

## Features

- Continuous environmental sensing
- Formatted LCD display with cycling readings
- Serial monitor output for data logging
- Clean, well-commented Arduino code

---

## Tech stack

`C++` · `Arduino IDE` · `DHT library` · `Adafruit BMP library`
